# Gate

- Gate = `tools/vflab-run bash tools/gate.sh` (user ruling: all fvapi work — builds, gates, spikes, tests — runs on vflab; this overrides the global `offload run` default for this repo; the desktop runs no fvapi build or check). Iteration = `tools/vflab-run bash tools/fast-gate.sh` (never the claim). Any other command that builds or runs fvapi code → `tools/vflab-run <cmd>`. Contract + predicates: `docs/contracts/U1-foundation.md`.
- `tools/vflab-run` needs `fvapi_gate.slice` on vflab (`bash tools/bootstrap-vflab.sh`, idempotent, asserts the live cgroup limits). Exit = the command's status; 125 = sync or output mapping failed; a signal, OOM kill or timeout (`FVAPI_VFLAB_TIMEOUT`, default 7200 s) never exits 0.
- Dev work saturates the gate slice (user ruling, `Decisions` → `Host`): no CPU pinning (`taskset`); independent builds, checks + long suites run concurrently, one workspace each (vflab-run locks per worktree; a second run on a busy workspace waits). Timing-capped suites (TestsU4 aggregate frames: 60 s cap, ≈ 40–50 s used) run without a concurrent full rebuild: a contended run flaked there.
- CI gate, once `main`'s CI is green: `bash tools/ci-gate.sh <unit>` (push `ci/<unit>`, green only when every shard job succeeded, branch deleted when green). Until then the full gate runs on vflab alone.
- Step ledger (contract G5) = `.gate/ledger.tsv` in the run's workspace (vflab keeps one per worktree). Each red classifies on the spot, before a rerun counts: `tools/vflab-run bash tools/gate-ledger.sh` lists unclassified reds, `… classify LINE product|gate|flake|planted` sets one, `… summary` = per-stage runs, reds by class + seconds = the usefulness record beside CI history.
- Campaign tier = time-boxed vflab runs at a unit's or phase's close (the P7b mutation refresh, `Decisions` → `Mutation currency`) + gate.yml's weekly schedule; open-ended searches (mutation sweeps, fuzz campaigns) run there, the gate replays their pinned findings.
- Gate timings on vflab (U2 P7-queue merge 011bfb6, in-gate, under ≈12 concurrent builder workloads): full 3851.9 s — `blackbox` 1889.2 s, `audit-probes` 806.4 s, `probes` 595.2 s, `self-audit` 409.9 s (6 domains), `capsule` 59.6 s, `tests-u3b` 29.8 s, `profile` 20.0 s; fast gate ≈ 7–30 s. Uncontended reference (U2 P5/P6): full 867.9 s. CI fans out shards `lean` (1159 s), `checks` (23 s), `audit` (703 s) in parallel (run 41587236208). Speedup rows: `blackbox` + `audit-probes` (`.agent/deferred.md`). U1 baseline: full 16.5 s, fast 1.2 s.
