- Windows (C8b) = `--windows FILE` (lines `name PARENT START CHECK`): at each CHECK the live/peak/ipeak/alloc bytes born on PARENT's thread since START (frees subtract only those births); a START while open = `restarts`; an allocation on another thread = `x` and a window open at END = `open`, both findings. Groups: w-a + w-b = `fresh-windows.c` (pre-START free, nested-return START, recursive parent, address-reuse self-check, 3-CHECK spine, pre-START realloc, unopened, restart, another thread; every C row incl. ipeak + every close row exact, in order; w-b findings = the thread control's `x C thread#0.0=1` + `x W thread#0=1`); w-lean = `lean_obj_once_cold` windows over closed terms (`fresh_ctl_closed` one term; `fresh_ctl_nested` a nested pair: 2 CHECKs, restarts 1; each second call unopened); w-mix = regions + windows in one program; lean-gmp = regions over big-Nat products kept (`fresh_ctl_big`) vs dropped. Not yet qualified: a window over the driver; the driver's GMP routes on the admit path.
- SUB cohort (C8b) = optional 5th window field `SUB=s1,…` (exe symbols ≠ PARENT): a birth on W's thread while W is open inside a SUB call (per-thread depth d > 0) is tagged ⇒ rows add `sub` (live tagged bytes), `subp`, `suba`, `subn` (SUB entries while open) and W rows `dsub` (d at close − d at open; ≠ 0 = finding `sub-unbalanced`); exact semantics = the observer's docstring. A window without SUB keeps its exact program + rows ⇒ an edit to the observer's program generation also reruns `python3 -I tests/store/model/fresh-genid.py OLD .lake/build/bin/fvapi --reach G,…` (OLD = the previous `fresh-observe.py`, ≥ 4b3f467; programs = every control program + each distinct `c8b-probe.py` program (22 at c043d09), each generated under none + each plant both observers know; rc 0 iff the groups whose program changed = the edit's stated reach; without `--reach` = pure identity, rc 1 on any change; firing: OLD = 4b3f467's observer, no `--reach` → rc 1, w-sub differs under none + 6 plants, same under sub-exit (its SUB return text is empty, so moving it changes nothing)). Groups: w-sub = `fresh-windows.c` `wctl_sub` (pre-START SUB birth, nested SUB, a tagged free inside, address reuse) + `wctl_sub2` (one window over two PARENT episodes: a tagged block born in episode 0, freed in episode 1 = born before that START ⇒ lowers neither live nor sub) + `wctl_subret` (START = the return of a SUB symbol of its own window); every C + close row exact; w-sub-lean = the w-lean windows with SUB `lean_obj_once_cold` (sub = live); w-sub-gmp = windows over `fresh_ctl_gmp_{add,sub,fuel}` inside `fresh_ctl_gmp_w` (subn 2 / 1 / 8 + live = sub predicted; sizes recorded, next bullet). One program loads ≤ 3 SUB windows | ≤ 6 plain on the control binaries (4 | 7 → E2BIG at load) ⇒ a fixture needing more runs as several fresh identical sessions; the driver's budget = its own measurement (driver 192774d9, `c8b-probe.py load`: ≤ 3 SUB windows per program = 45 / 51 / 57 probes; 4 → no attach within 60 s). A SUB probe joined to a `ret:` START runs its SUB return before the opening (d at open excludes the returning frame: control `subret`); joined entries run after their actions.
- C rows follow from the observer's stated semantics ⇒ never edited. Lean rows are compiler predictions ⇒ changed only with `.lake/build/ir` evidence in the commit body. Recorded rows = Lean 4.35.0 runtime behavior with no prediction (w-lean peak 36,288 + alloc 40,128 = `lean_mark_persistent`'s work list inside `lean_obj_once_cold`: 16,128 B allocated, 12,288 B peak, freed; lean-gmp (40, 136, 296) + (0, 136, 296); w-sub-gmp sizes: a 1-limb total kept 32 B (peak 104, alloc 192), a 2^513 fuel 96 B (peak 264, 352 B allocated per decrement), 8 decrements subp 360 + suba 2,816) ⇒ re-recorded only with a runtime change named in the commit body. A closed term's first read thus allocates transients past its persistent bytes ⇒ a C8b row reports peak + ipeak + alloc beside live.
- Lean region exports are called through closures read from refs: a direct call lets the C compiler inline the export and drop its symbol (the observer then exits 2: missing region symbol). A `Bool` result routes the closure through `_boxed`, which drops the export too ⇒ controls return `Nat`.
- Driver frames = `fresh-probe.py` over one committed region set per program (`fresh-regions-{a,b,c}.txt`): one bpftrace program loads ≤ 10 regions on vflab, 11 → E2BIG at load (bpftrace exits nonzero ⇒ fail closed); windows extend the shared allocation/free handlers ⇒ they share that budget. rc 1 on any finding (FINAL cross ≠ 0, a row with overlap ≠ 0, no FINAL row) or stderr problem — never relaxed. A region off the frame's path prints no row (`captureSections` = observation start; model-only regions in a pure frame).
- Route coverage = `fresh-probe.py … --routes`: every named candidate allocator entry of the exe + its libc counted, keyed `exe:SYM` | `libc:SYM` (the exe's own `free_sized` stays apart from libc's); rc 1 on a nonzero unprobed entry or none counted. Driver ed023a27 nonzero: libc free, malloc, realloc; exe mi_free, mi_free_size, mi_malloc. An allocation path inlined past every named entry stays invisible to the observer + the census alike (native residual).
- BEGIN prints `symbols probed=… absent=…`: an optional allocator entry missing from a binary is listed, never silently skipped. bpftrace stderr passes through. bpftrace 0.25 prints `Attached N probes` (BEGIN + END counted) and `WARNING: Map full` (exit 0) on stderr; the observer fails closed on a count mismatch or any lost/failed/error/map-full text.
- `run` + `attach_program` remove OUT first (`clear`: `sudo -n rm -f`, since bpftrace writes OUT as root and /tmp is sticky; rm refused or OUT still present ⇒ exit `cannot clear`, rc 1; fires on OUT = a directory). Readiness = OUT holds the BEGIN line, which bpftrace 0.25.0 drains only after its attach loops ⇒ a BEGIN line implies attached only while OUT is this run's alone. Recipe: `input-probe.py … OUT_DIR frame noop 1 0 model` twice into one OUT_DIR → both `Attached 41 probes`, rc 0, OUT recreated (new inode); without `clear` the second run grades the first run's rows and fails `attached none != generated 41`, rc 1.
