# u01-card-catalog
Premise = physical card catalog; kind drawers → typed claim cards; lookup → call slip; misses → acquisitions tray; answers → stamped circulation slips.

Palette: walnut #69472f; wood light #a57a50; paper #faf8ef; ink #292b29; library green #245746; caution plum #783451. Walnut serves physical drawer material, not a generic terracotta accent. Paper + typewriter stack follows index-card material; no serif.
Type: system sans for navigation; Courier New/monospace for cards, statements + slips. Scale 14/16/22/42px. Text measures ≤76ch; hashes wrap.
