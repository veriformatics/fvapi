# Instrument panel

Premise = vflab analyser front panel; specimen selector, input tray, readout, chart-recorder paper.

Palette: enamel #ced9d8; chassis #647878; ink #193535; paper #ffffff; pass #135b3d; warning #86451b. No decorative plots: recorder prints real records.

Type: system sans for engraved controls (14/16/22 px); system monospace for display, input, proof + recorder (13/16/48 px). Plain labels; uppercase only the instrument's physical readout.

```
[fvapi / vflab analyser                 host lamp]
[specimen switch bank] [ACCEPT / REJECT readout ]
[catalog, all entries] [input tray + run control]
[entry dossier     ] [replay lamp + local check]
[chart-recorder roll: answers | demand           ]
```

Principles: one bolted chassis, not cards; inset dark green readout = dominant element; rectangular mechanical switch bank; paper recorder has perforations + ruled lines; lamps carry explicit text, never color alone. Full proof dossier sits below controls, readable rather than crammed into the metaphor. Mobile stacks the actual instrument modules. Keyboard uses native controls; visible focus; no animation.

Finish = API-backed catalog/entry/recorded/lookup/check/log flows; eleven captured states inspected; no external assets.
