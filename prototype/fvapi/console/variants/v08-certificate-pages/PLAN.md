# Certificate pages

Premise = technical-document library; catalog = contents, entries = datasheets, answers = certificates, logs = register. A certificate records a server answer, never independent verification.

Palette: paper #ffffff; bench #e5eaf0; ink #172c43; binding #244f78; quiet #516477; caution #814719. Status pairs label + border, never hue alone.
Type: system sans = document, headings 36/26/20/16; monospace = exact Lean, hashes, commands (not labels). Body 16/1.6, reading width 68ch.

```text
fvapi / technical documents                  Prototype | Print
Contents | Look up | Run check | Demand register | Answer register
                 DOCUMENT SHEET
                 Library / certificate no.
                 Title                       [status]
                 Claim, bounded by evidence
                 Exact statements
                 Trust + independent replay
                 File manifest
                 Licence / source
```

Distinctive choices: blue binding strip, broad white document margins, technical-document metadata table, square stamped status, an inset quotation for the claim, actual print stylesheet. No dashboard cards, aggregate metrics, ornament seals or implied third-party certification. Form controls live in a document request slip; returned answers form new document sections. Screen gutters = page context, not paper texture. Mobile = one flat reading column. Print hides navigation/forms, retains result + evidence.

Finish = live relative API; every required state captured + visually inspected; keyboard focus + reduced motion; variant-only files; worktree commit. Mock catalog currently has 3 summaries rather than the brief's 5; render every returned entry.
