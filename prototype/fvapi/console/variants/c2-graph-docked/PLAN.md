# Graph with control dock

Premise = the library is a circuit of evidence; a compact side dock operates it while the entire dependency network remains in view.

Palette: canvas #eef2f6; ink #22364b; cobalt #2456a6; rule #718195; accept #146345; demand #a66108. White node surfaces.

Type: system sans controls + graph (13/15/20/28px); system monospace input, hashes + recorder (12/14px). Prose ≤76ch.

```
[fvapi / Library circuit                       proof is portable]
[entry       subject      closure      shared ] [entry selector ]
[entry -------artifact-----groups------ runtime] [verdict readout]
[entry  --------------------------/      hubs ] [editable input ]
[dangling demand                              ] [lookup / check ]
[chart-recorder strip / answers | demand / actual records        ]
[evidence dossier: statements / replay / hashes / source         ]
```

Graph owns the canvas. All catalog entries remain visible; full manifests supply each neighborhood, requirements are deduplicated hubs. Closure files collapse into one counted node per entry; its dossier expands counted directory groups into file/hash lists instead of dozens of unreadable rectangles. Missing mock manifests are explicitly marked unavailable. Lookup lights the whole matched path; checks light the checker node; demand hangs unattached. Text graph is an optional disclosure, not a graph/list mode. Recorder uses ruled horizontal records, not dashboard cards. Dock is flat white, no enamel or chassis. Mobile retains a horizontally scrollable graph and stacks the dock. Native controls, focus outlines, no motion.

Finish = eleven API-backed states captured + inspected; GET-only live-shape inspection; files limited to this directory.
