# Signal bench

Premise = one signal-flow schematic: the input tray, proof graph + verdict terminal form a single drawing; the recorder is its output strip.

Palette: sheet #f7f8fc; ink #273044; trace #65519b; quiet #667084; accept #17634d; fault #a33b24. White node faces use #ffffff.
Type: system sans controls + prose (13/15/20/30 px); system monospace code + verdict (12/14/38 px). Prose ≤76ch.

The graph is functional infrastructure, not a separate illustration. Jointed traces connect native controls and live evidence nodes. Lookup lights evidence traces; checks light only the checker circuit. Recorded replay has an explicit open circuit, never a green path. Misses become unconnected input pins. Directory-grouped closure nodes expand into exact file hashes. A small output terminal is the one bold element; no enamel, shadows or decorative animation. Mobile keeps the circuit order vertically; the native text content is the graph's accessible alternative.

Finish: API-backed catalog + entry + recorded + lookup-hit/miss + accept/reject/409 + demand/answers + 390px mobile; each capture inspected. Mock cannot return full recorded manifests: show summary + explicit unavailable state. Live deploy remains MAIN's check.
