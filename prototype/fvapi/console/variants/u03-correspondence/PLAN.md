# Correspondence file

Premise = formal verification as exchange of signed letters + enclosures; reply never substitutes for independent checking.

Palette: archive blue #243f62; writing ink #202f3c; envelope white #ffffff; folder blue #dce5ed; rule gray #acbbc8; warning plum #703a59.
Type: Georgia correspondence headings (36/26/20); system sans navigation + body (16/14); system monospace only statement/hash/command bytes (13). Serif is the letter material, on white/blue rather than cream/terracotta.

Distinctness: broad blue filing rail; envelope-fold motif on the letter; address block rather than dashboard header; enclosure inventories retain complete hash bytes; signed-library voice remains plain + concise. No chat bubbles, animated feeds, KPI cards, decorative seals implying cryptographic verification. Replay status is provenance, not a trust badge. Forms are outgoing letters, replies append below. Mobile folds the rail above the letter. Focus = thick blue outline; no motion.

Finish: live relative API fetches; every requested state captured + inspected; keyboard forms; responsive 390px; commit only variant files. Fixture data remains outside UI source.
